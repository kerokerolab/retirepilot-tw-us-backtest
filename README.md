# RetirePilot — 跨市場（台股／美股）20 年歷史回測、法定雙軌退休金與貸款自償模擬系統

這是一套結合 **400 檔台美股 20 年歷史月 K 真實股數累積回測**、**勞保老年給付＋勞退新制雙軌精算**、**退休目標逆向反推引擎（Goal-Seeking Solver）** 與 **貸款投入股市自償模擬（車貸／房貸／信貸／借新還舊 80/20 動態再平衡）** 的全方位理財推演系統。

## 四大核心頁籤功能

1. **頁籤 1：退休推算、勞保勞退與逆向反推**
   - 支援行政院主計總處 11 大行業薪資中位數快速帶入、階段式（每 5 年／10 年）與逐年自訂月薪。
   - 內建**勞保老年給付（A/B 式擇優月領或一次請領）**與**勞退新制個人專戶（雇主 6% + 自提 0~6%）**精算，自動扣減個人自籌退休金缺口。
   - 內建 **Goal-Seeking 逆向反推引擎**，鎖定目標月領或目標總資產後，毫秒級反推「每月儲蓄率」、「所需年化報酬率」、「預計退休年齡」與「期初單筆本金缺口」。
   - 同時模擬 5 種退休提領法則（經典 4% 法則、Guyton-Klinger 動態護欄、固定比例 4.5%、領息優先、國人薪資中位數提領法）。
2. **頁籤 2：台美股 1~N 支任意區間比較回測**
   - 支援 `2006-01` 至 `2026-10` 任意起迄年月回測與 7 組歷史事件快速區間按鈕。
   - 採用月 K 級別真實股數累積法（月初收盤買入、除息日再投入 DRIP、月底結算市值、期初 $T_0$ 本金錨定）與三級分流防失真機制。
3. **頁籤 3：貸款投入股市與自償模擬**
   - 支援信貸、房屋增貸（含寬限期）、車貸與理財型房貸。
   - 可切換「外部薪資另外償還」、「100% 買股純賣股自償」與「80/20 現金保留池 ＋ 定期借新還舊動態再平衡自償」，並支援真實歷史月 K 股價壓力測試與一鍵帶入頁籤 1。
4. **頁籤 4：系統架構與三級分流說明**

## 本機啟動方式

```bash
pip install -r requirements.txt
python3 backend_mvp/app.py
```

啟動後開啟瀏覽器造訪 `http://127.0.0.1:8000`（或直接雙擊打開 `prototype/retire_backtest_mvp.html` 離線使用）。
