# RetirePilot 跨市場（台股／美股）20年回測與退休理財模擬系統 — 規劃與架構設計書 (v1.2)

## 一、產品願景與核心定位
本系統旨在**將「專業級的台美股 20 年日資料歷史回測」轉化為「不熟悉股市的新手也能無痛上手的人生財務規劃體驗」**。
- **長期目標**：公開上線之商業級 SaaS 理財規劃與回測平台（Freemium 訂閱制）。
- **MVP 起步策略**：採用輕量化架構（Python FastAPI 掛載輕量前端 ＋ SQLite 資料庫）與免費開源資料源，鎖定**「台股前百大市值上市公司、台股前百大 ETF（含 00631L 等槓桿型正 2）、美股前百大市值公司、美股前百大 ETF（合計 400 檔核心標的）」**，涵蓋散戶與退休族 98% 以上之回測與配置需求。

## 三、未滿 20 年標的之「三級分流防失真回測機制」 (Three-Tier Backfill & Unlisted Policy)

針對上市未滿 20 年（晚於 2006 年掛牌）之股票與 ETF，為杜絕一般回測工具「拿假指數填補個股或新型高股息 ETF」造成的失真誤導，本系統於 `universe_400.py`、`schema.sql`、`app.py` 與前端引擎全面實作 **三級分流處理機制**：

### 1. 400 檔標的之三級分流定義 (`STRICT_PROXY_WHITELIST` & `INCEPTION_YEAR_MAP`)
| 分類等級 | 適用標的條件與具體範例 | 上市前（未滿 20 年部分）處理原則 |
| :--- | :--- | :--- |
| **A 級：同指數雙胞胎 ETF<br>（白名單 1:1 代理）** | 追蹤完全相同底層指數且有更早上市之母 ETF：<br>• `006208.TW` (2012) ➔ 母標的 **`0050.TW`** (2003)<br>• `VOO` (2010) ➔ 母標的 **`SPY`** (1993)<br>• `QQQM` (2020) ➔ 母標的 **`QQQ`** (1999)<br>• `00679B.TWO` / `00687B.TWO` (2017) ➔ 母標的 **`TLT`** (2002) | 僅於使用者切換至「模式 2 或 模式 3」時，取用母標的真實歷史報酬代理回溯至 2006 年，並於表格與診斷橫幅明確揭露。 |
| **B 級：固定倍數大盤槓桿 ETF<br>（白名單數學公式代理）** | 追蹤明確大盤指數之單日固定 2 倍／3 倍槓桿 ETF：<br>• `00631L.TW` / `00675L.TW` (2014~2016) ➔ **`0050.TW` × 2 倍（扣融資與管理費拖累）**<br>• `TQQQ` (2010) ➔ **`QQQ` × 3 倍**<br>• `UPRO` (2009) ➔ **`SPY` × 3 倍** | 僅於「模式 2 或 模式 3」時依母指數真實報酬乘上槓桿倍數並扣除融資成本合成，以測試正 2／正 3 經歷 2008 金融海嘯之極端最大回撤。 |
| **C 級：無替代指數之標的<br>（嚴格禁止假代理：`proxy = NULL`）** | • **所有晚於 2006 上市之個股**：如 `6669.TW` 緯穎 (2019)、`META` (2012)、`TSLA` (2010)<br>• **無早年對應指數之高股息／多因子／主題 ETF**：如 `00878.TW` (2020)、`00919.TW` (2022)、`00929.TW` (2023)、`00940.TW` (2024)、`SCHD` (2011)、`JEPI` (2020) | **嚴格禁止編造上市前假指數！** 依下方三種回測模式誠實截斷或進行動態權重暫泊。 |

### 2. 頁籤 2（歷史回測實驗室）三種處理模式切換
1. **模式 1（預設｜嚴格真實上市日截斷 `strict_truncate`）**：
   - **單檔獨立曲線**：每檔標的僅從其真實掛牌年份（`inception_year`）開始繪製，上市前年份留空（`null`），圖表以空心圓圈標示真實起點。
   - **自組投資組合**：自動以組合內所有標的之**「最晚真實上市年（Common Inception Year）」**作為共同起算年，100% 忠於真實掛牌歷史。
2. **模式 2（開啟 A/B 級白名單代理回溯 ＋ C 級無替代標的誠實截斷 `whitelist_proxy`）**：
   - A/B 級白名單 ETF（如 `00631L.TW`、`VOO`、`006208.TW`）回溯至 2006 年；但若組合內含有 C 級無代理標的（如 `00878.TW`），仍誠實截斷於該 C 級標的之真實上市年（2020 年）。
3. **模式 3（白名單代理 ＋ C 級未上市期間權重暫泊動態入列 `dynamic_parking`）**：
   - 組合完整回測 20 年（2006–2025）；在 C 級標的尚未掛牌之早期年份（如 2006–2019 年 `00878.TW` 尚未上市），將其權重**自動按比例暫泊分配給組合內當時已上市之標的**，直到掛牌當年才於年度再平衡時正式納入。

### 3. 頁籤 1（退休推算模擬器）短歷史樣本「貝氏收斂保護（Bayesian Shrinkage）」
當自選組合之實際回測年數 $N_{\text{yr}} < 10$ 年（未經歷完整牛熊循環，例如僅涵蓋近 3～5 年多頭市場）時，帶入頁籤 1 推算未來 30 年退休會自動啟動貝氏收斂：
$$w = \min\left(1.0,\; \frac{N_{\text{yr}}}{10.0}\right), \quad \text{CAGR}_{\text{退休推算}} = w \cdot \text{CAGR}_{\text{短期實測}} + (1 - w) \cdot \text{CAGR}_{\text{同類資產20年長期基準}}$$
並在畫面頂部顯示黃色保護橫幅（同時提供一鍵切換回「原始短期年化」之按鈕），防止新手將短期牛市報酬直接線性外推 30 年。

## 四、核心回測與四大退休提領規則公式 (Simulation Engine)

| 提領規則名稱 | 數學運作邏輯 | 優缺點與適用情境 |
| :--- | :--- | :--- |
| **1. 經典 4% 法則 (固定實質購買力)** | 首年提領目標支出 $L_1$，之後每年不論股市漲跌皆隨通膨調整：$W_{\text{withdraw}, k} = W_{\text{withdraw}, k-1} \times (1 + \pi)$ | 購買力最穩定，但若退休初期遇大熊市且本金不足 25 倍年支出，會有資產歸零風險 |
| **2. Guyton-Klinger 動態護欄法則** | 當年度實際提領率超過初始提領率上限護欄（$+20\%$）時減薪 10%；低於下限護欄（$-20\%$）時加薪 10% | 兼顧生活品質與本金安全，能有效化解「退休首年遇到金融海嘯」的破產危機 |
| **3. 固定比例提領法 (Fixed %)** | 每年固定提領當年初剩餘總資產的固定比例（如 $4.5\%$）：$W_{\text{withdraw}, k} = 0.045 \times W_k$ | 數學上**永遠不會破產**，但股市大跌年份可支配生活費會同步縮水 |
| **4. 存股領息優先＋差額賣股法** | 優先花用當年度組合配發之稅後現金股利 $D_k$；若 $D_k < L_k$，才賣出價值 $(L_k - D_k)$ 之零股補足生活費 | 最符合台灣存股族心理習慣，牛市保留本金、高殖利率組合幾乎不需賣股 |

| **2. 週期性額外大筆支出模組** | • 支援新增多筆大額花費（例如：**每年固定出國 10 萬元**、**每 5 年換手機 4 萬元**）<br>• **全生命週期生效**：從**現在（工作累積期）一路扣除至退休提領期**，金額隨通膨率自動調升 | • **累積期**：自當年度投入本金／投資組合資產中扣除<br>• **退休期**：直接疊加於當年度退休提領金額上 |

| **4. 新增第 5 種提領法：「國人薪資中位數提領法」** | • 以行政院主計總處最新公告之**「全體受僱員工全年總薪資中位數 ÷ 12」**作為每月退休生活費基準<br>• 支援設定**中位數加減比例**（如 `80%`、`100%`、`120%`），退休後每年隨通膨率調升 | 介面清楚加註說明：「採用最近年度行政院主計總處公告之工業及服務業受僱員工全年總薪資中位數 ÷ 12（含年終與獎金攤提）」 |
| **5. 整合政府公告「各行業薪資中位數」試算** | • 於頁籤 1「目前月薪」輸入框旁整合**「各行業薪資中位數」下拉選單**<br>• 統一採用主計總處最新公告之**「各大行業全年總薪資中位數 ÷ 12」**並附註說明，選取後一鍵帶入月薪欄位 | 內建主計總處各大行業別（資通訊、金融保險、製造業、醫療保健、批發零售、住宿餐飲等）最新年度薪資中位數查核表 |
